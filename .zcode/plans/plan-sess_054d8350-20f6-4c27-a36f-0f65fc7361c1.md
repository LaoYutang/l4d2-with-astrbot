# 开发计划：群内闪传链接 → 面板下载任务

## 交互流程（按你的规范）

管理员在已配置群内发送 QQ 闪传链接（`https://qfile.qq.com/q/xxx`）：

1. 立即回复：`检测到 QQ 闪传链接，请选择要上传的服务器（回复序号，输入其他内容取消，30 秒内有效）：` + 服务器列表（**仅列出同时配置了面板地址和面板凭据的服务器**；一台都没有时提示先去配置页填写并结束）。
2. 管理员回复数字 → 调用该服务器面板的 `POST /download/link/parse` 解析；回复其他字符/序号越界 → 提示原因并取消；30 秒无回复 → 回复"超时取消"。
3. 解析成功后，**只列出面板标记为支持的条目**（`.vpk/.zip/.rar/.7z`），序号、文件名、大小；不支持的文件完全不出现、不可选。**若没有任何可展示的文件，直接提示"未解析到可下载的文件"并结束**。
4. 管理员回复数字（`,`/`，`分隔多选）或"全部" → 逐个调用 `POST /download/add`；其他字符/越界 → 提示原因并取消；30 秒无回复 → "超时取消"。
5. 返回添加结果汇总（成功/失败逐条），**不查询下载进度**。
6. 非管理员：完全静默，不做任何回复。

## 改动清单

### 1. 配置模型：每台服务器新增两个字段（config_manager.py）
- `default_config()` 的 server（40-47 行）新增 `"panel_url": ""`、`"panel_token": ""`。
- `validate_config()` 的 server 循环（189-201 行）新增：`panel_url` 用现成的 `_optional_url()`（254-262 行，校验 http/https 并去尾部 `/`）；`panel_token` 用 `_string()`（213-219 行，允许空串）。
- 语义：两者都非空才视为"可上传服务器"。`panel_token` 填面板密码或 30 天临时授权码均可（都是 `Authorization: Bearer`）。

### 2. 配置页（pages/settings/app.js，纯 vanilla JS 动态渲染）
- `createEmptyServer()`（58-65 行）加两个空字段；`normalizeConfig()` 的 server 映射（97-103 行）加 `asText`。
- `createServerCard()`（517-550 行模板、553 行 `fieldNames`）：新增"面板地址"（占位符 `http://1.2.3.4:27020`）和"面板凭据"（密码框）。
- 密钥显示开关（568-573 行）目前写死 `rcon_password`，改为按 `data-target` 区分，支持第二个密码框。
- `validateConfig()` server 循环（616-633 行）：`panel_url` 非空时校验 HTTP/HTTPS。
- `index.html`、`style.css`、i18n 均不动（服务器卡片是 JS 动态生成，CSS 复用 `.field`/`.secret-control`）。

### 3. 新增 panel_client.py（不依赖 astrbot，便于单测）
- `PanelError`；`PanelClient(base_url, token)`：
  - `parse_download_link(url)`：`POST {base}/download/link/parse`，JSON body，Bearer 头，超时 60 秒，返回 `items` 列表。
  - `add_download_task(file_url, filename, referer)`：`POST {base}/download/add`，multipart 表单，Bearer 头，超时 30 秒，返回面板文本（"下载任务已添加"）。
  - 错误映射：非 2xx 优先取响应 JSON 的 `message` 字段，否则取文本；连接/超时给中文提示；不记录 token。
- 纯函数（供单测）：`format_file_size()`、`parse_number_selection(text, max_index)`（只接受数字与中英文逗号/空格分隔，返回索引列表或"越界/非法"信号）、`is_all_selection(text)`、`filter_supported_items(items)`（只保留 `supported=true` 的条目）。

### 4. main.py 新处理器
- 新增 import：`from astrbot.core.utils.session_waiter import session_waiter, SessionController, SessionFilter, USER_SESSIONS`（`astrbot.api.all` 不导出这些）和 `from .panel_client import ...`。
- `_MemberSessionFilter(SessionFilter)`：会话标识 `f"{event.unified_msg_origin}:{event.get_sender_id()}"`，保证多人各自独立（框架默认是按群，不满足需求）。
- `_cancel_existing_session(session_id)`：同群同管理员再次发链接时，先 `USER_SESSIONS[session_id].session_controller.stop()` 并等其清理完成再开新会话，避免旧会话 30 秒后误报"超时取消"和新会话被旧清理逻辑误删（框架内部 API，需加保护，失败降级为忽略新链接）。
- 新 handler `@filter.regex(r"https?://qfile\.qq\.com/q/[A-Za-z0-9_-]+")`，流程：
  1. `_get_group_config` 判空静默返回；`_check_permission(event, admin_users)` 不通过静默返回。
  2. 过滤出 `panel_url` + `panel_token` 均非空的服务器；为空则回复配置提示并结束。
  3. `yield` 第一步提示 → `await select_server(event, session_filter=_MemberSessionFilter())`（`@session_waiter(timeout=30)` 定义在 handler 内部，闭包保存选择结果）。
  4. 回调解法：合法序号 → `controller.stop()`；非法/其他字符 → `await event.send(...)` 提示原因并 `stop()`；超时由外层 `except TimeoutError: yield event.plain_result("超时取消")` 处理。
  5. `yield "正在解析闪传链接，请稍候..."` → `PanelClient.parse_download_link()`；异常回复错误并结束。
  6. 用 `filter_supported_items()` 过滤解析结果；为空则回复 `未解析到可下载的文件（仅支持 .vpk/.zip/.rar/.7z）` 并结束；否则 `yield` 文件列表（只含支持项，超过 30 个文件分多条消息发送，避免超长）。
  7. 第二步 waiter（30 秒）解析"全部"或数字多选；非法 → 提示原因并取消。
  8. 逐个调用 `add_download_task()`（原样传 `file_url`/`filename`/`referer`），汇总每个文件成功/失败，`yield` 最终结果。
  9. `finally: event.stop_event()`，防止消息继续进入其他处理器。
- 文案固定："已取消"、"超时取消"、"序号超出范围（1-N），已取消"、"未解析到可下载的文件（仅支持 .vpk/.zip/.rar/.7z）"。

## 关键决策与风险
- 不支持格式的文件对管理员完全不可见；文件名与序号仅基于支持项生成。
- 30 秒仅约束用户输入等待；面板 HTTP 调用超时为添加 30 秒、解析 60 秒（解析要实时访问 QQ，可能超过 30 秒，超时报错结束而非静默）。
- 面板直链带签名时效，解析成功后立即添加。
- 面板若启用 IP 访问控制，需放行机器人出口 IP；自签名 HTTPS 会失败，建议面板用 HTTP 或有效证书。
- 本次不含：读群文件、下载进度查询、工坊链接走面板、配置页"测试连接"按钮（均可在后续单独加）。
