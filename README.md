# L4D2 Server Query Plugin for AstrBot

这是一个用于查询 Left 4 Dead 2 (L4D2) 服务器状态的 AstrBot 插件。

## 功能

- **查询单个服务器**: `查询 [服务器名]`
  - 显示服务器地图、人数、延迟以及详细玩家列表。
  - 自动附带连接指令或直连链接。
  - 服务器名匹配时忽略空格，`查询1服` 与 `查询 1 服` 等价；未匹配到本群配置中的服务器时不回复。
- **临时查询**: `connect [IP:Port]`
  - 直接查询指定 IP 和端口的服务器状态，该服务器无需出现在配置中。
  - 如果端口未指定，默认为 27015。
- **综合查询**: `综合查询`
  - 显示所有配置服务器的简略状态（地图、人数、延迟）。
  - 如果配置了黑盒语音，会显示每个服务器对应语音频道在线人数。
- **语音频道查询**: `语音 [服务器名]`
  - 查询指定服务器对应黑盒语音频道的在线名单。
  - 需要配置黑盒语音机器人 ID、Token、房间 ID 和频道 ID。
- **获取连接地址**: `服务器列表` / `服务器地址` / `连接指令`
  - 列出所有服务器的 `connect IP:Port` 指令，方便复制。
  - **一键连接**: 如果在配置中设置了 `connectBaseUrl`，将生成可点击的 HTTP 连接链接（如使用 steam-connect 服务）。
- **地图真名**: 只要在配置中设置了 `mapNameUrl`，查询类指令（`查询`、`connect`、`综合查询`）就会把地图代码（如 c1m1_hotel）转换为中文真名（如 死亡中心: 旅馆），查询结果缓存 1 小时。
- **RCON 指令**: `设置 [服务器名] [指令]`
  - 向指定服务器发送 RCON 指令并获取返回结果。
  - 支持前缀匹配，例如 `设置1服 status`。
  - **权限要求**: 仅在配置文件 `admin_users` 列表中的用户可执行。
  - **配置要求**: 需在配置文件中为该服务器设置 `rcon_password`。
- **重启服务器**: `重启 [服务器名]`
  - 发送 `_restart` 指令重启服务器的快捷方式。
  - 同样需要管理员权限和 RCON 密码。
- **创意工坊解析**: 发送创意工坊链接
  - 自动解析 Steam 创意工坊链接，显示地图/Mod的标题、文件大小和下载链接。
- **闪传链接上传地图**: 管理员发送 QQ 闪传链接（`https://qfile.qq.com/q/xxx`）
  - 机器人先让管理员回复序号选择要上传的服务器（仅列出同时配置了面板地址与面板凭据的服务器），再选择要下载的文件，随后调用该服务器 L4D2 管理面板的下载接口创建任务，下载完成后由面板自动安装到服务器。
  - 选择文件时可回复多个序号（用逗号分隔），或回复“全部”下载全部受支持的文件；仅支持 `.vpk`、`.zip`、`.rar`、`.7z`，其他格式不会出现在列表中。
  - **权限要求**: 仅群组 `admin_users` 中的管理员可用，其他成员发送链接不会有任何回复。
  - 每一步选择需在 30 秒内回复，超时自动取消。

## 使用示例

> 下文样例中的服务器名、玩家名、面板数据均为虚构。
> 所有指令都只在「当前群已出现在配置的群组中」时才响应，未匹配到服务器名等情况下的静默行为在各节末尾说明。

### 查询单个服务器 `查询 [服务器名]`

发送 `查询 1服`，机器人先回复等待提示，再回复查询结果：

```text
正在查询 1服，请稍候...
```

```text
服务器: 大家一起打僵尸
地图: 死亡中心: 旅馆
人数: 15/32 (🎧3)
延迟: 42ms

在线玩家:
- 玩家甲 (1:05:03)
- 玩家乙 (12:34)
- 玩家丙 (0:42)

点击直连: https://connect.example.com/1.2.3.4:27015
```

字段说明：

- `地图` 只有在配置了 `mapNameUrl` 时才显示中文真名，否则显示原始地图代码；结果缓存 1 小时。
- `(🎧3)` 是黑盒语音频道在线人数，仅在「全局机器人凭据 + 群组 `hh_room_id` + 服务器 `hh_channel_id`」都配置且查询成功时出现，语音查询失败不影响服务器状态展示。
- 玩家名后的括号是游戏时长，超过 1 小时显示 `时:分:秒`，超过 1 天显示 `天:时:分:秒`。
- 开启 `safeMode` 后玩家名脱敏为 `玩**丙` 形式（保留首尾字符，中间替换为等长 `*`）。
- 最后一行：配置了 `connectBaseUrl` 时为 `点击直连: {connectBaseUrl}/{IP}:{Port}`，否则为 `连接指令: connect {IP}:{Port}`。

| 情况 | 机器人回复 |
| --- | --- |
| 服务器连不上 | `无法连接到服务器 1服，可能服务器离线或网络问题。` |
| 当前无人在线 | 结果以 `当前无玩家在线。` 结尾 |
| 服务器名不在本群配置中 | 不回复 |
| 当前群不在配置中 | 不回复 |

### 临时查询 `connect [IP:Port]`

发送 `connect 1.2.3.4:27016`：

```text
正在查询 1.2.3.4:27016，请稍候...
```

```text
服务器: 对抗专用服
地址: 1.2.3.4:27016
地图: c1m1_hotel
人数: 3/8
延迟: 18ms

在线玩家:
- 玩家丁 (0:42)

连接指令: connect 1.2.3.4:27016
```

与 `查询` 的区别：多一行 `地址`，且因为没有关联服务器配置，不会显示语音人数。端口省略时按 27015 处理，`connect 1.2.3.4` 等价于 `connect 1.2.3.4:27015`。

### 综合查询 `综合查询`

```text
正在查询所有服务器状态...
```

```text
=== L4D2 服务器概览 ===
服务器: 2/3 在线
人数: 15/40
-------------------------
[1服] 大家一起打僵尸
　　  15/32   🎧3
　　  死亡中心: 旅馆
[2服-对抗] 对抗专用服
　　　　　 0/8
　　　　　 c1m1_hotel
[3服] 离线或无法连接
```

结构说明：

- 表头依次是「在线服务器数/配置总数」和「在线人数/总位子数」。
- 每台在线服务器占 3 行：`[别名] 服务器真名`、人数（可选语音在线人数）、地图真名。第二、三行的缩进按别名宽度对齐，使用全角空格补齐，以适配非等宽字体。
- 人数列左对齐，按所有在线服务器中最宽的人数串补空格，所以较短的人数行末尾会带有多余空格。
- 服务器真名超过 20 个显示宽度、地图真名超过 15 个显示宽度时截断并追加 `...`；中文按 2 个显示宽度计算。
- 地图名包含 `|` 时只取 `|` 之前的部分。
- 离线服务器只显示 `[别名] 离线或无法连接` 一行，不计入在线数与人数统计。
- 本群未配置服务器时回复 `本群未配置任何服务器。`

### 语音频道查询 `语音 [服务器名]`

发送 `语音 1服`：

```text
=== 1服 语音频道 ===
在线人数: 2
- 玩家甲
- 玩家乙
```

- 频道无人在线：`1服 语音频道当前无人在线。`
- 黑盒凭据、群组 `hh_room_id`、服务器 `hh_channel_id` 任一未配置，或接口查询失败：不回复。
- 接口只返回用户 ID 时，插件会先拉取房间成员列表换成昵称，取不到昵称则显示用户 ID。

### 获取连接地址 `服务器列表` / `服务器地址` / `连接指令`

配置了 `connectBaseUrl` 时：

```text
=== 服务器列表 ===
点击下方链接连接服务器：
[1服] https://connect.example.com/1.2.3.4:27015
[2服-对抗] https://connect.example.com/5.6.7.8:27016
```

未配置时：

```text
=== 服务器列表 ===
[1服] connect 1.2.3.4:27015
[2服-对抗] connect 5.6.7.8:27016
```

该指令只输出配置中的地址，不会联网查询服务器状态。

### RCON 指令 `设置 [服务器名] [指令]`

管理员发送 `设置 1服 status`：

```text
正在向 1服 发送指令: status ...
```

```text
服务器响应: hostname: 大家一起打僵尸
version : 2.2.3.2
...
```

服务器名按前缀匹配，`设置1服 status` 与 `设置 1服 status` 均可；匹配时按名称长度倒序尝试，因此 `1服` 与 `1服-对抗` 同时存在时会优先命中更长的那个。

| 情况 | 机器人回复 |
| --- | --- |
| 未匹配到服务器名 | `未找到指定名称的服务器。` |
| 服务器名后没有指令 | `请输入要执行的指令。` |
| 发送者不在 `admin_users` | `权限不足：您不在管理员列表中。` |
| 服务器未配置 `rcon_password` | `服务器 1服 未配置 RCON 密码，无法执行指令。` |
| 服务器无文本响应 | `指令已发送。服务器无文本响应。` |
| 超过 15 秒未完成 | `操作超时：连接服务器耗时过长，请检查服务器状态或网络连接。` |
| 认证失败等异常 | `RCON 执行出错: RCON 认证失败：密码错误` |

### 重启服务器 `重启 [服务器名]`

管理员发送 `重启 1服`：

```text
正在尝试重启 1服...
```

```text
指令已发送。服务器正在重启...
```

实际动作是向服务器发送 `_restart` 指令，权限与 `rcon_password` 要求同 `设置`。

### 创意工坊链接解析

发送任意包含创意工坊链接的消息，例如 `https://steamcommunity.com/sharedfiles/filedetails/?id=123456789`：

```text
正在解析创意工坊链接，请稍候...
```

单品：

```text
=== 创意工坊单品解析 ===
标题: 某张三方图
文件: some_map.vpk (123.45 MB)
下载: https://example.com/some_map.vpk
--------------------
```

合集会把每个子项依次列出，标题行为 `=== 创意工坊合集解析 ===`。

| 情况 | 机器人回复 |
| --- | --- |
| 链接无法解析 | `解析失败: 无法解析该链接 (非合集或 API 无数据)` |
| 解析接口请求失败 | `解析失败: API 请求失败或未返回数据` |

### 闪传链接上传 `https://qfile.qq.com/q/xxx`

仅管理员发送时才有响应，完整交互如下，每一步都需在 30 秒内回复。

1. 管理员发送 `https://qfile.qq.com/q/AbCdEf123`：

```text
检测到 QQ 闪传链接，请选择要上传的服务器（回复序号，输入其他内容取消，30 秒内有效）：
1. 1服
2. 2服-对抗
```

2. 回复 `1` 后：

```text
正在解析闪传链接，请稍候...
```

```text
1服 解析成功，共 2 个可下载文件，请选择要下载的文件（回复序号，多个用逗号分隔；回复“全部”下载全部；输入其他内容取消，30 秒内有效）：
1. some_map.vpk（123.45 MB）
2. other_mod.vpk（8.00 MB）
```

3. 回复 `1,2`（或 `1，2`、`1 2`、`全部`）后：

```text
已提交 2 个下载任务：
- some_map.vpk
- other_mod.vpk
```

部分文件提交失败时，成功与失败会分两段列出：

```text
已提交 1 个下载任务：
- some_map.vpk

提交失败 1 个：
- other_mod.vpk：面板返回错误（HTTP 500）：磁盘空间不足
```

| 情况 | 机器人回复 |
| --- | --- |
| 发送者不是管理员 | 不回复 |
| 群里没有同时配置 `panel_url` 与 `panel_token` 的服务器 | `本群尚未配置带面板地址和面板凭据的服务器，请先在插件配置页填写后再试。` |
| 解析链接失败 | `解析闪传链接失败：{错误信息}` |
| 面板没有返回受支持的文件 | `未解析到可下载的文件（仅支持 .vpk/.zip/.rar/.7z）。` |
| 回复非数字内容 | `已取消` |
| 序号超出范围 | `序号超出范围（1-2），已取消` |
| 30 秒内未回复 | `超时取消` |

下载任务由面板异步执行并在完成后自动安装到服务器，机器人只负责提交任务，不会回报下载进度。

## 安装

1. 将本插件文件夹放入 AstrBot 的 `data/plugins/` 目录下。
2. 安装依赖:
   ```bash
   pip install -r requirements.txt
   ```
   或者手动安装 `python-a2s` 和 `python-valve`。

## 配置

插件首次运行后，会在 AstrBot 数据目录下生成配置文件：

```text
data/plugin_data/astrbot_plugin_l4d2_query/config.json
```

请根据需要修改配置。该文件位于插件目录之外，更新插件不会被覆盖。

> 从旧版本升级：如果插件目录下还残留着旧的 `config.json`，请把其中的内容手动复制到上面的新路径（新路径不存在时插件会先生成一份默认配置，直接覆盖它即可），确认无误后删除插件目录下的旧文件。

### WebUI 配置页面

在支持 Plugin Pages 的 AstrBot 版本中，可以从“插件 → L4D2服务器查询 → 服务器配置”打开可视化配置页面。页面支持：

- 管理全局 URL、玩家名脱敏和黑盒机器人凭据；
- 添加、删除群组以及群组管理员；
- 在每个群组内添加、删除多台服务器，支持配置 RCON 密码、面板地址与面板凭据；
- 校验重复群组、重复服务器名、URL 和服务器端口；
- 保存后立即刷新插件运行时配置，无需重载插件。

可视化页面读写的就是上面这个数据目录下的 `config.json`。此版本插件要求 AstrBot v4.28.0 或更高版本。

支持为不同的群组配置不同的服务器列表。

```json
{
    "connectBaseUrl": "https://xxxx.xxxx.xx", // 可选：配置一键连接的基础URL
    "mapNameUrl": "https://xxxx.xxxx.xx", // 可选：配置地图真名查询API，需要时不带最后的斜杠
    "safeMode": false, // 可选：开启后查服玩家名只保留首尾字符，中间用等长 * 脱敏
    "hh_bot_id": "", // 可选：黑盒语音机器人ID
    "hh_bot_token": "", // 可选：黑盒语音机器人Token
    "group_configs": [
        {
            "group_id": 12345678,
            "group_name": "主群", // 可选：群组名称，仅用于配置页展示
            "hh_room_id": "", // 可选：黑盒语音房间ID
            "admin_users": [123456789], // 管理员QQ列表，只有列表中的用户可以使用重启指令
            "servers": [
                {
                    "name": "主服务器",
                    "address": "127.0.0.1:27015",
                    "hh_channel_id": "", // 可选：黑盒语音频道ID
                    "rcon_password": "your_rcon_password",  // 可选：配置 RCON 密码以启用重启功能
                    "panel_url": "http://1.2.3.4:27020",  // 可选：L4D2 管理面板地址，与 panel_token 同时填写才可用于闪传上传
                    "panel_token": "your_panel_password"  // 可选：面板密码或临时授权码
                },
                {
                    "name": "对抗服",
                    "address": "1.2.3.4:27016",
                    "hh_channel_id": ""
                }
            ]
        },
        {
            "group_id": 87654321,
            "servers": [
                {
                    "name": "二群服务器",
                    "address": "5.6.7.8:27015"
                }
            ]
        }
    ]
}
```
